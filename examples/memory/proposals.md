# Proposals

Agent suggestions for the read-only `system/` folder — roles, playbooks, skills.
Agents append to `## Open`. You approve one by moving its line to `## Accepted`;
`brain evolve` applies that section and nothing else, then deletes the lines it applied.
A line you turn down goes to `## Declined`, which agents read before proposing again.
The Studio's Improvements page and Admin's Overview do both moves with one click.

Format: `- [system/roles/qa.md] what to change — why (project, date)`
